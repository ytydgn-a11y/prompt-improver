# כפתור "שיפור" לפרומפטים ב-Claude

כפתור קטן מעל שורת הכתיבה באפליקציית Claude למחשב (לשונית Code). לחיצה עליו משכתבת את הפרומפט שכתבתם לפי כללי פרומפטים טובים, ומחזירה את הגרסה המשופרת לשורת הכתיבה. הכפתור מופיע בכל צ'אט, גם בצ'אט חדש לפני ההודעה הראשונה.

## דרישות

- Windows 10 או 11.
- אפליקציית Claude למחשב, מחוברת לחשבון עם **מנוי Claude בתשלום**.
- היכנסו פעם אחת ללשונית **Code** באפליקציה לפני ההתקנה. אין צורך להתקין שום דבר נוסף: Claude Code מגיע עם האפליקציה.

## התקנה

1. חלצו את `prompt-improver.zip` לתיקייה קבועה (למשל "המסמכים"). **שמרו את התיקייה**: תצטרכו אותה כדי להתקין מחדש או להסיר.
2. לחצו פעמיים על `install.cmd`. ייפתח חלון שחור שמראה את ההתקנה.
   - אם מופיע "Windows הגן על המחשב שלך": לחצו "מידע נוסף" ואז "הפעל בכל זאת". אם האנטי-וירוס עוצר את הקובץ, אשרו אותו.
3. בהתקנה הראשונה נפתח דף בדפדפן ("Claude Code would like to connect"): התחברו לחשבון Claude אם צריך, ולחצו **Authorize**. ההתקנה ממשיכה לבד.
   - הדפדפן לא נפתח? העתיקו את הקישור שמופיע בחלון השחור לדפדפן.
   - אם הדף מציג קוד: העתיקו אותו, חזרו לחלון השחור, הדביקו (לחיצה ימנית) ולחצו Enter.
   - האישור הזה נדרש פעם אחת, ותקף לשנה.
4. ההתקנה הסתיימה כשמופיע בירוק `Done` ואחריו "Press any key to continue". לחצו על מקש כלשהו כדי לסגור את החלון.

הכפתור מופיע מיד מעל שורת הכתיבה בלשונית Code, ועולה אוטומטית בכל הפעלה של Windows.

## שימוש

- **"שיפור"** (לחיצה שמאלית): משפר את הטקסט שבשורת הכתיבה. זה לוקח כ-10 שניות. בזמן הזה אל תקלידו, אל תעתיקו ואל תעברו לחלון אחר.
- **"ביטול"**: מחזיר את הטקסט המקורי. זמין עד ששולחים את ההודעה או מנקים את השורה. אם הטקסט בשדה שונה מאז השיפור, לא נעשה דבר.
- **לחיצה ימנית על "שיפור"**: פותחת את תיקיית הכללים.
- **שאלה אמריקאית של Claude:** אפשר לבחור "Other", לכתוב תשובה חופשית בשדה שלו וללחוץ "שיפור". התשובה משתפרת בתוך השדה הזה, ו"ביטול" זמין כדקה.
- **הטקסט ננעל ברגע הלחיצה:** רק מה שכתוב בשדה באותו רגע נשלח לשיפור, והתוצאה מודבקת אוטומטית לאותו שדה. אם עברתם לצ'אט אחר בזמן השיפור, היא מודבקת ברגע שתחזרו לצ'אט המקורי (עד 10 דקות), גם אם בינתיים שיניתם את גודל החלון או את הפריסה. אם הטקסט המקורי נערך, נשלח או נמחק בינתיים, שום דבר לא מודבק ומופיעה הודעה.
- שורת כתיבה ריקה: הכפתור מציג הודעה ולא משנה דבר.
- הכפתור מופיע רק מעל שורת הכתיבה של צ'אט (גם חדש), לא בהגדרות או בדפים אחרים. כשמופיעה הודעה מעל שורת הכתיבה (למשל "Message queued"), הכפתור עולה מעליה.

הטקסט נשלח לשכתוב ל-Claude דרך החשבון שלכם, וכל שיפור נספר במכסת המנוי.

## הוספת כללים (שיפור האופן שבו הוא משפר)

הכללים הם קבצי טקסט רגילים בתיקייה `%LOCALAPPDATA%\PromptImprover\rules`.
כדי לפתוח אותה: לחיצה ימנית על "שיפור", או Win+R, הקלידו `%LOCALAPPDATA%\PromptImprover\rules` ולחצו Enter.

- `00-core.md` הוא קובץ הכללים הבסיסי. התקנה מחדש מעדכנת אותו, ולכן שינויים שתעשו בו יימחקו.
- **כלל חדש = קובץ חדש.** הדרך הקלה: העתיקו את קובץ הדוגמה `_example-my-rules.md`, הסירו את ה-`_` מתחילת השם ושנו אותו למשל ל-`50-my-rules.md`. כתבו בו את הכללים שלכם בשפה רגילה. התקנה מחדש אף פעם לא דורסת אותו.
  - יוצרים קובץ בפנקס הרשימות? ב"שמירה בשם" בחרו סוג "כל הקבצים", כדי שהשם יסתיים ב-`.md` ולא ב-`.md.txt`. קובץ `.txt` לא נקרא.
- הקבצים נקראים לפי סדר השמות (00 ראשון). כלל שצריך לגבור על כלל קודם יקבל מספר גבוה יותר.
- כדי לכבות קובץ בלי למחוק אותו, הוסיפו `_` לתחילת השם.
- השינויים נכנסים לתוקף בלחיצה הבאה, בלי הפעלה מחדש.

## פתרון תקלות

- **הכפתור לא מופיע:** ודאו שאתם בלשונית Code ושהחלון של Claude לא ממוזער. אם עדיין לא, הריצו שוב את `install.cmd`.
- **"אין צ'אט פתוח וההתחברות פגה":** האישור מההתקנה פג (אחרי שנה) או בוטל. הריצו שוב את `install.cmd` ואשרו בדפדפן.
- **יומנים:** בתיקייה `%LOCALAPPDATA%\PromptImprover`: `overlay.log` לכפתור, `install.log` להתקנה האחרונה.
- אל תמחקו ואל תערכו את התיקייה `%LOCALAPPDATA%\PromptImprover\kit`: התוסף נטען ממנה.

## הסרה

לחיצה כפולה על `uninstall.cmd` מהתיקייה שחילצתם. ההסרה מוחקת את הכפתור, את ההפעלה עם Windows, את האישור השמור ואת היומנים. תיקיית `rules` שלכם נשמרת, ולמחיקה מלאה מחקו גם את `%LOCALAPPDATA%\PromptImprover`.

**הערה:** הכפתור משתמש לרגע בלוח ההעתקה (העתקה והדבקה של הטקסט), ומחזיר אחר כך את מה שהיה בו.

## למפתחים: איך זה בנוי

| חלק | תפקיד |
|---|---|
| `overlay/PromptImproverOverlay.cs` | תוכנת הכפתור. מזהה את שורת הכתיבה על המסך, מעתיקה את הטקסט, שולחת אותו לשכתוב ומדביקה את התוצאה. |
| `plugin/` | תוסף Claude Code. צ'אט פתוח לוקח ממנו את הטיוטה (דרך `127.0.0.1:47811`) ומשכתב אותה. |
| `rules/` | כללי השכתוב. ההתקנה מעתיקה אותם ל-`%LOCALAPPDATA%\PromptImprover\rules`. |
| `overlay/TokenSetup.cs` | יוצר לכפתור טוקן משלו (`claude setup-token`) ושומר אותו מוצפן למשתמש Windows הנוכחי. |
| `install.ps1` / `uninstall.ps1` / `find-claude.ps1` | בנייה, התקנה, הפעלה עם Windows, הסרה, ואיתור Claude Code. |

כשאין צ'אט פתוח (למשל מיד אחרי שפותחים את Claude), הכפתור מפעיל את Claude Code בעצמו, עם הטוקן שנשמר בהתקנה. הבדיקות: `claude plugin test plugin`.
